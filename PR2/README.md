# PR2 - Diseño Arquitectónico con DecidArch

## Proyecto: Trigon Ascent

Esta entrega corresponde a la segunda etapa de desarrollo del proyecto **Trigon Ascent**, enfocada en el análisis y toma de decisiones arquitectónicas mediante la metodología **DecidArch**.

Trigon Ascent es un videojuego 2D pixel art compuesto por 30 niveles distribuidos en tres mundos, con un sistema de combate estratégico basado en cartas de habilidades propias de cada personaje.

## Trabajo realizado

Durante esta etapa se desarrollaron y ajustaron las siguientes tarjetas de DecidArch:

- Project Card.
- Stakeholder Cards.
- Concern Cards.
- Event Cards.
- Quality Attributes y criterios asociados.

## Principales ajustes realizados

A partir de la revisión de las primeras versiones de las tarjetas, se aumentó el nivel de especificidad de los escenarios y decisiones arquitectónicas.

Entre los principales cambios se encuentran:

- Incorporación de criterios medibles para los Quality Attributes.
- Definición de requisitos de rendimiento, incluyendo FPS y tiempo de respuesta.
- Especificación de resoluciones objetivo para compatibilidad.
- Mayor contextualización de los eventos que pueden afectar la arquitectura.
- Definición de escenarios de expansión del roster de personajes.
- Evaluación del impacto de una reducción del equipo de desarrollo.
- Incorporación de un superboss obligatorio como nivel adicional.
- Evaluación de distintas alternativas para niveles, cartas, combate, animaciones, sistema de guardado y movimiento 2D.
- Análisis de los impactos positivos, negativos y neutrales de cada alternativa sobre los Quality Attributes.

## Decisiones arquitectónicas analizadas

Se estudiaron alternativas relacionadas con:

1. Estructuración y reutilización de los 30 niveles.
2. Representación y administración de cartas y habilidades.
3. Modelo de combate.
4. Relación entre cartas y animaciones.
5. Persistencia y recuperación del progreso del jugador.
6. Sistema de movimiento para escenarios 2D pixel art.
